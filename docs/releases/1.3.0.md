First GitHub release of Home WiFi for Android.

- Router device inventory, trusted-device labels, protected devices and verified Wi-Fi blocking.
- Timed blocks with durable automatic unblock, access schedules and connection history.
- Connection health, outage history and an on-demand home-server speed test.
- AdGuard protection monitoring, timed pauses, domain exceptions and filter refresh.
- Release/resume the router dashboard session for technician access.
- Minimal settings with technical options grouped under Advanced settings.
- In-app updates from GitHub Releases: a notice above the header, verified APK downloads and Android-approved installation.

Download the APK below to install or update Home WiFi. Android 8.0 or newer is required. This app requires a configured self-hosted Home WiFi backend and targets the inspected Huawei HG8546M firmware; no router credentials or backend API token are included in the APK.

The APK is built and signed by GitHub Actions. SHA256SUMS verifies the download; update.json is consumed by the in-app updater. Backend binaries are not distributed in this release. Existing backend deployment instructions remain in the repository.
