Adds control of the router's Wi-Fi mode and channel, with a channel analyzer.

- New Settings > Wi-Fi radio screen: switch the 2.4 GHz mode (802.11b, g, n, b/g or b/g/n mixed) and pick a channel or Auto. Each change restarts Wi-Fi, asks for confirmation, and is only reported as done after the router confirms it.
- Channel analyzer: scans nearby Wi-Fi networks from your phone, charts how crowded each 2.4 GHz channel is, and suggests the quietest one. It needs the location permission Android requires for Wi-Fi scans; nothing is stored or sent.
- Updated look across the app (shared card, settings and device-list components).

Requires the matching backend (this repository, `main`) with `VERIFIED_RADIO_WRITES=true` in the server's `.env` to allow changes; reading and scanning work without it. Android 8.0 or newer is required.

The APK is built and signed by GitHub Actions. SHA256SUMS verifies the download; update.json is consumed by the in-app updater.
